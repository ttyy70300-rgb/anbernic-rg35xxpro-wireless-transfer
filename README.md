# PocketTransfer —— 安伯尼克 RG35XX Pro 无线传输软件

给 **Anbernic RG35XX Pro** 掌机和 **Windows 电脑**之间加一条"无线传文件"的路：
不用拔 TF 卡、不用数据线、不用装驱动 —— 掌机点开应用，电脑双击一个 exe，
两边互相拷文件。

```
┌─────────────────┐    WiFi 局域网     ┌──────────────────┐
│  RG35XX Pro     │ ◄────────────────► │  Windows 10/11   │
│  (掌机端 Python) │   TCP 48200       │  (单文件 exe)     │
│                 │   UDP 48211 发现   │                  │
└─────────────────┘                    └──────────────────┘
```

## 功能特性

- **自动发现**：电脑打开就自动扫描局域网找掌机，不用配 IP；
  连成功一次就记住，下次启动自动填上（IP 变了再连一次新的就换）
- **双栏互拷**：左本机、右掌机，四列文件表（名称/后缀/大小/修改时间），
  选中点「复制进掌机 / 复制进电脑」
- **安全确认**：写入、新建目录、删除文件都要**双端确认**——
  电脑弹窗一次，掌机上还要按 A 才真正执行；删除前明确写"不可恢复"
- **读写锁**：掌机上按 SELECT 随时上锁/解锁，电脑端右上角状态
  最多 4 秒自动跟着变
- **掌机端首页**：屏幕上半看连接状态和关键日志，下半是按键说明，
  不用记操作
- **新建目录 / 删除文件**：都在电脑端点按钮、掌机上按 A 确认后完成
- **稳定连接**：心跳保活 + 掌机侧 10 分钟空闲超时，传完歇一会儿再传不会断
- **掌机 IP 占位提示**：从没连过时输入框留空并提示怎么填，
  绝不预填别人的 IP

## 快速开始

### 电脑端（Windows 10/11）

直接下载 [`pc/dist/PocketTransfer.exe`](pc/dist/PocketTransfer.exe)，
双击就能用，**不需要装 Python**。

想从源码运行：

```bash
python pc/main.py                # 需要 Python 3.10+（自带 tkinter）
python pc/main.py --host x.x.x.x # 跳过自动发现，直连指定 IP
```

### 掌机端（RG35XX Pro）

要求：官方固件 20260522（Ubuntu 22.04，自带 Python 3.10）。

把本仓库 **`APPS/` 文件夹里的内容**复制到 TF 卡的 `Roms/APPS/` 下即可：

```
APPS/PocketTransfer.sh      →  Roms/APPS/PocketTransfer.sh      （菜单启动脚本）
APPS/PocketTransfer/        →  Roms/APPS/PocketTransfer/        （程序本体，6 个 .py）
APPS/Imgs/                  →  Roms/APPS/Imgs/                  （菜单图标）
```

用读卡器或本软件本身都能拷。装完菜单里就会出现应用图标。
（`PocketTransfer.sh` 是 Linux 脚本，如果用 Windows 编辑过它，
注意保持 LF 换行符——直接复制不改动则无需关心。）


**启动**：掌机菜单 → APPS → PocketTransfer。保持前台运行即可被电脑发现。

## 怎么用

| 想做什么 | 怎么做 |
|---|---|
| 连接 | 电脑点「扫描」自动找；找不到就手填 IP 点「连接」 |
| 传文件到掌机 | 左栏选中文件 →「复制进掌机 →」→ **去掌机按 A 确认** |
| 传文件到电脑 | 右栏选中文件 →「← 复制进电脑」 |
| 新建文件夹 | 「在掌机当前目录新建文件夹」→ 输名字 → 掌机按 A |
| 删除掌机文件 | 右栏选中（按钮才亮）→ 电脑弹窗确认 → 掌机再按 A |
| 锁定/解锁写入 | **在掌机上按 SELECT**，电脑端 4 秒内同步显示 🔓/🔒 |
| 换本机目录 | 位置下拉框（盘符 + 桌面/下载等）或「选目录」 |

掌机端按键：**A** 确认/进入、**B** 返回/拒绝、**SELECT** 锁定/解锁、
**L2/R2** 切换页面、**START** 退出、摇杆/十字键移动。
每次弹确认框时，屏幕下半部分都会显示当前可用的按键说明。

常见问题（扫描不到掌机、上传卡住等）见
[docs/阶段2联调手册.md](docs/阶段2联调手册.md) 第六节。

## 它是怎么制作的

### 硬件与固件底子

- 掌机：Anbernic RG35XX Pro，全志 H700（4×Cortex-A53 @1.512GHz），
  1GB LPDDR4，640×480 IPS 屏
- 固件：官方 20260522，Ubuntu 22.04 LTS，内核 4.9.170，
  自带 Python 3.10 —— **掌机端零依赖**，不用 pip 装任何东西

### 掌机端怎么画界面、怎么读按键

官方固件跑着 dmenu 启动器，应用启动时画面是被合成器叠上去的，
直接写 `/dev/fb0` 会被原厂图层盖住。所以掌机端显示层用
**SDL2 直写 framebuffer**（`sdl_display.py` / `fb.py`），
按键则直接读 `/dev/input/event*`，用 `struct.unpack("qqHHi")`
解 24 字节事件。十字键是 HAT0X/HAT0Y（EV_ABS），摇杆是 ABS 轴 2/3/4/5，
死区 800。轴码和物理方向的对应关系**不能靠 evdev 标准猜**，
项目里内置了一个"引导式标定页"（诊断页按 A），按提示摇一圈
自动记录每个轴的真实极性。

### 自定义二进制协议

两端用一套自定义 TCP 协议通信（`handheld/net.py` ↔ `pc/client.py`，
常量在 `pc/protocol.py`，**两边必须逐字一致**，有专门测试盯着）：

- 包格式：`MAGIC(2B=0x504B) + OP(2B) + LENGTH(4B) + 负载`，全大端
- 发现：UDP 广播 48211 端口问"有人在吗"，掌机回机型/IP/端口
- 数据：TCP 48200；文件切成 64KB 块传输，**每块带 4 字节序号**，
  服务端校验连续性 —— 早期版本吃过"序号混进数据、大小对内容错"的亏
- 17 个操作码：PING / 设备信息 / 列目录 / 下载 / 上传 / 建目录 / 删除 /
  ACK / NAK / NOTICE / BYE…（完整表见联调手册第三节）
- 安全三道门（全在掌机侧）：`safe_join` 路径校验（防 `../` 穿越越界）→
  忙碌拒绝（同时只服务一台电脑）→ **确认框**（写/建目录/删文件必弹）

### 几个关键设计决策（都踩过坑）

1. **确认框用"直接动作键"，不用焦点模型**：按 A 一律是允许、
   按 B 一律是拒绝，高亮框只是视觉装饰。第一版用了焦点默认值，
   用户"直接按 A 想允许，结果执行的是拒绝"——不可逆操作上这是事故。
2. **状态变更必须主动通知对端，而且通知必须有人接**：
   掌机按 SELECT 切读写，最初只改本地标志，电脑永远不知道；
   改成主动推 NOTICE 后又发现电脑空闲时不读 socket、通知没人收。
   最终方案是两头一起动：掌机主循环改 0.5 秒轮询、及时发通知；
   电脑心跳从 25 秒提到 4 秒、并从 PING 升级成 GET_DEVICE_INFO——
   一次往返同时保活 + 把最新权限带回来，通知丢了也有兜底。
3. **收尾由显式 FILE_END 宣告，不靠"收满就 ACK"**：否则最后一个
   结束包会被当成"未知操作"，用户拒绝时双方状态机还会错位。
4. **自动扫描用"时间窗"不用"数遍数"**：启动立即扫 1 次，
   之后每 7 秒一次，满 5 分钟停——用户看得懂，也好解释。
5. **设备侧默认值绝不写开发者的环境值**：IP 输入框宁可留空加占位提示，
   也不预填"我自己的" IP；连成功才记住，之后永远记"最近一次成功的"。

### 界面

- 掌机端：自绘 UI，5 个页面（首页/状态/文件/网络/日志）+ 引导式标定页，
  首页按黄金比 61.8% 分上下两半
- 电脑端：tkinter 双栏 + 醒目提示条（需要去掌机按键时整条横幅提醒），
  深色主题，PyInstaller 打成 11.4 MB 单文件 exe，双击即用

### 测试与质量

**9 个测试套件、740 项断言，全绿**。其中最有价值的是
`tools/test-loopback.py`：不插掌机，在本机把"服务端+客户端"
两端跑起来走完全部协议路径，几秒钟逮到过好几个
"表面正常、实际错误"的 bug（文件静默损坏、传完就断连等）。
另有掌机按键语义专项测试、首页版面测试（含"按键说明表防漂移"）、
PC 端 UI 结构冒烟测试等。改代码后跑一遍 `tools/` 下的测试即可回归。

### 开发历程：六轮真机实测迭代

这个软件是**边用边改**出来的，每一轮都来自真实使用反馈：

1. **第一阶段**：打通显示/按键（framebuffer、SDL2、input 标定）
2. **第二轮**：协议与基础传输（自动发现、双栏 UI、打包 exe）
3. **第三~四轮**：左右栏换位、盘符下拉、按钮文案、传输后断连、
   需人工操作时的醒目提示；确认框按键语义重做、扫描时间窗、
   双端确认删除（新增 DELETE_BEGIN 协议）
4. **第五轮**：掌机端首页（黄金比版面 + 按键说明表）
5. **第六轮**：SELECT 状态同步、IP 记忆、默认目录改桌面

完整的设计决策与踩坑记录都在 [docs/](docs/) 里。

## 已知限制

- 不支持整目录传输（需逐个文件），不支持删除文件夹（返回明确原因码）
- 一次只服务一台电脑（1GB 内存机器上单线程串行最稳）
- 无断点续传、无加密（纯局域网场景 + 掌机侧确认门；需要可上 TLS）
- 删除无回收站，掌机上直接删，不可恢复
